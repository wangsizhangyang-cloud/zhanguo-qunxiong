## 〇、历史模拟教学关 · 骊山之难

### 情境（第〇課 · 开卷 · 王在镐京）

宗周镐京。幽王已废申后与太子宜臼，立褒姒为后、伯服为太子；卿士虢石父当政，国人皆怨。幽王为烽燧大鼓，数举烽火博褒姒一笑——诸侯至而无寇，其后益不至。三川皆震、岐山崩时，太史伯陽甫言「周将亡矣」，幽王弗聽。你执西垂之秦（秦襄公）：宗周将乱，你的兵要不要东赴勤王？何时赴、从哪一省出、出多少——一切都由你决定，并由回合结算。

### 课程（6步，右下任务栏随时提示）

第〇課 開卷 · 王在鎬京 → 第一課 觀其國 → 第二課 動員 → 第三課 **骊山之难**（四幕：申侯怒 → 王命舉烽🔥兵莫至 → 驪山之殃·幽王崩 → 平王東遷）→ 第四課 救周逐戎（收复镐京；围城第2回合触发「犬戎虏褒姒、尽取周赂——守军折半」）→ 第五課 封侯建國（逐犬戎出犬丘，受封岐西）。

课堂规则：
- **骊山之难为历史锚点**：固定在第三課发生，不可被玩家提前改写；你若先取镐京，守军会被兵锋卷出。
- **勤王之师**：骊山之难后秦得锐士50入咸阳。
- **犬戎转守**：取赂自散、不再远征。

### 👑 周幽王 · 殿上对话（agentic）

教学关内顶栏 **👑 周幽王**——对话对象就是王本人。他按【目标】与【记忆库】（本纪所载的废立、烽火、申侯之怨等既行之事）行动，只接收场景中可感知之事（纪年、王师态势、围城战况、来使之言）。

- **说话方式**：以浅近白话为主（像明清小说人物对白），少量使用「寡人／卿／来使」等古称；不堆四字句、不引经据典、不写成骈文。
- **不套路、不复读**：每次只回应来使刚说的这件事；系统把王最近说过的句子列为【禁句】，模型若复读或换字眼重复，会自动重试一次换说法；再重复则由脚本接管，绝不把同一句话再抛给玩家。
- 玩家快键四问：问三川之震 / 陈申侯之怨 / 请举烽备戎 / 臣告退。
- **随进程而变的表现**：
  - 第〇～第一課（宗周宴安）：慵懒自矜、以戏谑处之——被问灾异则不肯当真（史载幽王弗聽）；
  - 第二課之后（申人在東方聚兵）：由傲慢转强辩与忌惮；
  - 第三課骊山之难：四幕中**幽王崩於骊山**——殿上之门从此阖上，面板只留临终一句（「寡人为数举烽火，诸侯不至——今日之祸……何至是耶！」）与《史记》原文；
  - 崩后输入与发送键封禁，对话止息。
- 模型输出单动作 JSON（`say` 对来使说话 / `goto` 幸骊山·还宫 / `stay` 居宫 / `silence` 沉默），世界判定先行——不可行之事不成行（如东都之行被拒）。
- **四种运行模式**（🔑 模型里切换）：
  1. **本地代理（推荐）**：先运行 `node _server.mjs` 或双击 `run_serve.bat`。浏览器只连 `http://127.0.0.1:8642/__llm`，代理自动读取 `战国图鉴\siliconflow_key.txt`（也认 `deepseek_key.txt` / `openrouter_key.txt` / 环境变量），**没有跨域问题，也不用把 Key 填进网页**。
  2. **硅基流动直连**：填 `https://api.siliconflow.cn/v1` + Key，默认模型 `deepseek-ai/DeepSeek-V3.2`。
  3. **DeepSeek 官方**：填 `https://api.deepseek.com` + Key。
  4. **OpenRouter**：填 `https://openrouter.ai/api/v1` + Key（浏览器跨域友好）。
  - Key 只存本机 localStorage，绝不写入项目文件；本地代理的 Key 由本机文件读取，页面看不到。
  - 不填 Key、服务器没开或调用失败时，幽王按脚本应对；脚本库同样做了去重，不会连续复读同一句。
  - 🔑 面板里的「🔌 测试连接」可先验证通路，再进殿对话。

## 〇.五、地产式地图 v3.1（钢铁雄心4式郡域地塊）

**打开方式不变**：双击 `index.html`。若只想看地图，可打开 `map_preview.html`（不进对局的独立地图预览与自检）。

**v3.3 真实投影（实景改制，双击 index.html 即玩）**：36 块地块以《史记》《战国策》所载各城邑的**真实经纬度**为锚点，边界由加权 Voronoi（泰森多边形）自动生成——离哪块锚点近、就归哪块，故块间相对方位与相对大小一律照真实历史地图（楚最大七块、山东四块小、关中-蜀-楚跨地摊开）；随后叠加 14px 六边形世界采样，边界照旧用共享 Catmull-Rom 贝塞尔曲线有机化。背景层并画真实走向的 河水·江水·淮水 与 秦·赵·燕·齐·魏 五道长城（分据《史记·货殖列传》《战国策》与《史记·匈奴列传》《楚世家》《秦本纪》引据）。

- **地块名＝战国郡域**：上郡、陇西、北地、汉中、巴、蜀、太原、巨鹿、代、云中·九原、琅邪、清河、宛·南阳、巫黔中、洞庭、陈、宜阳、上党、河内、上谷、辽西·碣石、辽东…… 郡名与置郡事件均引《史记》（例如「攻楚汉中，取地六百里，置汉中郡」《史记·秦本纪》）。
- **地块大小＝国幅引文**：悬停或省面板可见「📐 地块」一行，注明每块的规模史据（如汉中六百里、蜀巴「巴蜀亦沃野」）。国家级按各国「地方X里」折算：楚五千里＝7块（最大）／赵二千里＝5块／齐二千里四塞＝4块／燕二千馀里＝4块／魏千里＝3块／韩不满九百里＝4块（皆小）／秦（关中+巴蜀汉中，《货殖列传》称其地居「天下三分之一」）＝8块；周王畿＝1块。**36 块恰应《秦始皇本纪》「分天下以为三十六郡」。**
- **地块几何属虚构**：网格抽象归【虚构】（为了能玩和维护），边界方位按引文描绘（如「齐西有清河」→清河地西接邯郸，「燕东有朝鲜辽东」→辽东东缘临海）。
- **玩法变化**：邻居=格相接自动生成；大城驻厚重，郡县薄弱；无海军——海（勃海/东海/南海/漠北/西羌）不可通行，齐燕隔海、临淄-辽东隔海峡。
- **渲染细节**：每块的地形（▲山/~水）按六边格布置；海岸线比陆界抖得更厉害（噪声更大）；省界细线是静态层，国界粗线只在归属变化的那一支上重描；高亮/选中用同一份曲线，故描边不飘。
- **教学关**：`startTutorial` 调 `rebuildMap(['haojing','quanrong'])` 把关中西缘割出**镐京**、陇西东缘割出**犬丘**（4格+4格），并把这些地自动并回邻接（ADJ 自动重算）。退出教学时 `rebuildMap()` 还原 36 块。

## 一、核心玩法（v2.1 命令制）

1. **选国**：秦/赵/齐/楚/魏/韩/燕七选一，各国专属国策加成（另：周王畿静守不出兵）。
2. **资源**：💰金 🌾粮，每回合产出；粮尽兵溃10%。
3. **招募**：15兵种；费=cost×系数，train−2 回合成军；**资源不足时按钮自动置灰**。
4. **调兵/进攻**：均「下令」，`▶结束回合`统一结算（先调兵后开战）。
5. **战斗**：战力=Σ(兵×权重×地形)×克制×将领×城防±10%；战报含**战力构成明细**（前三主力）与技卡引据。
6. **克制链**：13条史实关系，用对兵种才打得动。
7. **将领**：16位战国名将+技卡（每战一次），引据《史记》《吴子》等。

**v3 新增体验**：地图悬停情报窗（归属/地形/兵力/产出/围城/地块规模史据）；纪年徽章（教学关显示 前781—…）；250ms 结束回合防抖；弹窗打开时 Space 误触被拦截；**⚙ 设置面板（简／繁切换 + 模型 API 入口）**。
